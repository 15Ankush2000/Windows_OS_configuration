# Lab 7 – Configuring Recovery

## Name
Lab 7 – Configuring Recovery (Windows Recovery, Backup, and Monitoring)

## Purpose
The purpose of this lab is to understand how Windows recovery tools work and how to use system recovery, backups, and monitoring utilities to diagnose and restore a system in case of failure.

## What I did
- Accessed Windows Advanced Startup and Recovery Environment  
- Used Command Prompt in recovery mode to navigate system directories  
- Booted into Safe Mode and explored limited system functionality  
- Viewed system boot logs (ntbtlog.txt) for troubleshooting  
- Created and configured a virtual hard disk (VHD) for backups  
- Set up Windows Backup and performed file backup and restore  
- Restored files from backup location successfully  
- Explored System Image Recovery options  
- Used Task Manager for performance monitoring  
- Created and ran a Performance Monitor Data Collector Set  
- Viewed system performance logs  
- Created and viewed custom Event Viewer logs for system events  

## Outcome
This lab helped build practical skills in system recovery, backup management, and performance monitoring, which are essential for troubleshooting Windows system failures and maintaining system reliability.
