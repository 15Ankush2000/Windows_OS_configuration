# Lab 2A – Configuring Users

## Overview
This lab focuses on managing local users and groups in a Windows environment using the MMC (Microsoft Management Console). It demonstrates how to create, modify, disable, delete, and rename user accounts.

## What I did in this lab
- Set up MMC with Local Users and Groups snap-in  
- Created multiple local user accounts with different settings  
- Modified user accounts (rename, disable, delete, and password change)  
- Created a local security group  
- Added users to groups to manage access control  
- Configured a home folder for a user account  
- Verified user and group changes through the system  

## Purpose
The purpose of this lab is to understand how Windows manages local user accounts and groups, and how these are used to control access and organize permissions on a system.
