# Lab 6 – Configuring Network Connectivity

## Name
Lab 6 – Configuring Network Connectivity (IPv4 Subnetting & Network Configuration)

## Purpose
The purpose of this lab is to understand IPv4 subnetting and practice configuring and verifying network connectivity in a Windows environment using tools like PowerShell, ipconfig, ping, tracert, and route.

## What I did
- Calculated IPv4 subnetting values (network address, host range, broadcast, etc.)
- Analyzed different subnet masks and IP address scenarios
- Configured network adapter (vEthernet) settings
- Manually set IP address and DNS configuration
- Used PowerShell and command-line tools to verify network settings:
  - `ipconfig /all`
  - `ping` (multiple targets)
  - `tracert`
  - `route print`
- Captured required screenshots for documentation (SS01–SS07)
- Verified network connectivity and routing information
